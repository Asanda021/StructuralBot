# StructuralBot — متره و برآورد ساختمان بتنی

ربات Telegram برای **متره و برآورد اولیه ساختمان‌های بتنی**. تمرکز محصول روی استخراج مقادیر اجرایی و گزارش‌دهی است، نه طراحی یا محاسبات سازه.

## محدوده محصول

- مدیریت پروژه و نام‌گذاری پروژه
- متره اولیه بتن برای فونداسیون، ستون، تیر، سقف و راه‌پله
- برآورد وزنی میلگرد بر اساس ضرایب kg/m³ قابل توسعه
- تفکیک مقادیر خالص و مقدار خرید با پرت
- بررسی اطلاعات قبل از ثبت محاسبه
- ویرایش ورودی‌های پروژه و محاسبه مجدد
- ذخیره دائمی پروژه‌ها و برآوردها در SQLite
- گزارش متنی پروژه
- ساختار آماده برای قیمت‌گذاری، PDF و Excel

## روش محاسبه

موتور محاسبات نسخه takeoff-1.0 است و خروجی را با متادیتای روش و فرضیات ذخیره می‌کند.

**نکته مهندسی:** وزن میلگرد در این مرحله «برآورد اولیه» بر مبنای ضرایب kg/m³ است و جایگزین نقشه سازه، لیستوفر یا BBS اجرایی نیست. مقدار بتن و قالب نیز بر اساس هندسه ورودی پروژه محاسبه می‌شود.

## معماری

- Python 3.14
- python-telegram-bot 22.5
- SQLite با WAL و Foreign Key
- Telegram Polling
- Health endpoint استاندارد Python
- موتور متره مستقل از رابط Telegram
- ذخیره ورودی و نتیجه به صورت JSON برای امکان نسخه‌بندی و گزارش حرفه‌ای

## اجرای محلی

```bash
pip install -r requirements.txt
BOT_TOKEN="YOUR_TOKEN" python bot.py
```

روی Render، متغیر محیطی BOT_TOKEN لازم است و سرویس Health روی PORT اجرا می‌شود.

## مسیر توسعه

1. متره جزئی‌تر اجزای ساختمان
2. قیمت‌گذاری و برآورد ریالی
3. فهرست‌بها و قیمت‌های قابل تنظیم
4. گزارش PDF و Excel
5. مصالح تکمیلی و نازک‌کاری
